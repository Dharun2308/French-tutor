# French Tutor audit — September 9, 2026

Scope: the application in `/home/multi_mind/French-tutor`, its local systemd
service, SQLite data integrity, learning and import workflows, AI providers,
Google Docs integration, Language Transfer audio, dependency advisories, and
phone browser behavior. This is a point-in-time audit, not proof that every
possible input, device, provider response, or future outage works correctly.

## Findings and changes

| Finding | Evidence and resolution |
| --- | --- |
| Vulnerable dependencies | Initial npm audit reported 17 affected dependency entries: 1 critical, 9 high, 6 moderate, 1 low. Updated Next.js and its ESLint config from 15.5.15 to 15.5.25, Drizzle ORM to 0.45.2, Drizzle Kit to 0.31.10, and vulnerable compatible transitive dependencies. Explicit PostCSS/esbuild overrides resolve dependencies pinned by upstream tools. Final dependency audit: zero advisories. |
| Cross-site browser writes accepted | A cross-site, text/plain settings request returned 200 against the disposable app. Shared API middleware now rejects foreign/opaque browser origins and cross-site writes. Same-origin and private-proxy writes remain supported; local jobs without an Origin header remain supported. This supplements the private network boundary, not application authentication. |
| Topic questions timed out despite healthy providers | Connectivity tests succeeded, but a real five-question batch exhausted all three 25-second limits. Question batches now allow 60 seconds per provider, or 90 seconds for batches above five. Theory and grading retain their shorter limits; retries remain disabled in the API SDK. A fresh real theory/questions/grading run then passed through Codex. |
| Failed legacy reviews silently discarded | Flashcards, multiple choice, drill, Foundations and sentence reveal could hide failed saves, show success or advance anyway. Saves now require an acknowledged success before revealing/advancing; errors retain the current answer/card and explain uncertainty. A shared synchronous lock blocks overlapping saves; typing and relevant controls disable while saving. Phrase review fetches now check HTTP status. |
| First-use settings race | Concurrent callers could both insert singleton settings. Initialization now tolerates that insert conflict. Disposable-DB regression checks eight simultaneous calls and one resulting row. |
| Lint did not run | `npm run lint` opened an interactive setup prompt. Added an ESLint flat configuration and an unattended command, fixed its error, and resolved the reported hook/directive warnings. |
| Integration tests depended on historical data/order | Phase 3 assumed exactly 14 items and an empty error-pattern history. It now checks the actual eligible set and the specific pattern's increment. Topics review inspected the last row without ordering, although SQLite used the UUID question index. It now explicitly orders attempts by ID; actual outage replacement routing was already correct. |
| Audio cancellation raised an uncaught exception | Reproduced `Controller is already closed` by interrupting HTTP audio responses. Replaced the Node-to-Web stream adapter with a bounded file reader that handles cancellation during pending reads and closes its file handle once. Added range/cancellation unit coverage and exercised interrupted HTTP/browser downloads. |
| Invalid service setting | `StartLimitIntervalSec` was in `[Service]` and ignored. Moved it to `[Unit]`; retained a validated service template under `scripts/`. |
| Stale operational documentation | README now distinguishes the current persistent local installation from the original Vercel app and warns against production `db:push` or rebuilding the running `.next` directory. Corrected the legacy Again interval and rating keys. |

## Practical limits and follow-up

- AI output is variable. The successful French examples and grading checks are
  samples, not a linguistic certification of every generated lesson. Longer
  batches can now take longer before fallback; complete outages remain visible.
- Legacy verb/Foundations review endpoints do not have durable request-ID
  deduplication across reloads/devices. The UI now blocks concurrent in-flight
  saves and reports failures, but a connection lost after the server commits is
  ambiguous; follow the displayed reload guidance. Imported-item reviews do
  have tested durable request IDs. Broader offline replay was not added.
- Browser speech is the selected mode. Actual voice availability and audible
  output depend on the learner's device; headless testing cannot verify that.
  Paid OpenAI speech was left disabled. Language Transfer MP3 playback was tested.
- Google Docs writes were tested with fixtures, not by modifying real lesson
  notes. OAuth currently works, but the OAuth app's publishing status and future
  token renewal remain unverified (a pre-existing setup caveat).
- The app remains a private, single-user application with no login. Public
  deployment, new device/Tailscale enrollment, full disaster recovery, and
  exhaustive multi-device concurrency were outside this local audit.
